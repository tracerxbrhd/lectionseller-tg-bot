# LectionSeller TG Bot

[English](README.en.md) | Русский

Telegram-бот и web-admin panel для продажи лекций и обучающих материалов по фармакологии.

LectionSeller TG Bot объединяет каталог материалов, оплату, автоматическую выдачу доступа, личный кабинет пользователя в Telegram и административную панель для управления образовательным контентом.

## Назначение

Проект предназначен для преподавателей, авторов курсов и образовательных команд, которым нужен управляемый канал продажи цифровых материалов через Telegram.

Пользователь взаимодействует с ботом: открывает каталог, выбирает лекцию или блок, оплачивает покупку и получает доступ к материалам внутри Telegram. Администратор управляет каталогом, ценами, файлами, пользователями, платежами и обращениями через web-интерфейс.

## Пользовательский Функционал

- Главное меню Telegram-бота.
- Каталог с иерархией `Раздел -> Блок -> Лекция`.
- Карточки лекций и блоков с описанием и ценой.
- Покупка отдельной лекции.
- Покупка блока целиком.
- Оплата через YooKassa.
- Ручная проверка оплаты из Telegram.
- Автоматическая выдача доступа после успешной оплаты.
- Раздел "Мои покупки".
- Просмотр доступных материалов только после проверки покупки.
- Получение PDF, видео, аудио, изображений и текстовых материалов.
- Раздел поддержки с отправкой вопроса администратору.
- Статический раздел "О проекте".

## Административная Панель

Web-admin panel позволяет управлять проектом без работы с базой данных напрямую:

- авторизация администратора;
- dashboard со статистикой;
- управление разделами;
- управление блоками;
- управление лекциями;
- загрузка и редактирование материалов;
- настройка цен и активности товаров;
- просмотр пользователей;
- просмотр покупок;
- просмотр платежей;
- просмотр обращений в поддержку;
- ручная выдача доступа;
- ручной отзыв доступа.

## Платежи И Доступы

Платежная логика вынесена в отдельный сервисный слой. YooKassa используется как текущий провайдер оплаты.

После подтверждения оплаты система:

1. переводит покупку в оплаченный статус;
2. создает доступы к связанным лекциям;
3. сохраняет платежные данные и raw payload;
4. показывает материалы пользователю в разделе "Мои покупки".

Повторные webhook-уведомления и повторные проверки оплаты обрабатываются идемпотентно.

## Работа С Контентом

Материалы привязываются к конкретным лекциям. Поддерживаются:

- PDF;
- видео;
- аудио;
- изображения;
- текстовые материалы.

Файлы могут храниться на сервере или выдаваться через `telegram_file_id`.

## Защита Контента

Проект использует максимально доступные меры защиты в рамках возможностей Telegram:

- выдача материалов только после проверки доступа в БД;
- отсутствие публичных ссылок на материалы;
- хранение файлов под контролем backend;
- выдача контента внутри бота;
- `protect_content=True` для Telegram-сообщений и файлов;
- проверка путей локальных файлов;
- логирование факта выдачи материала пользователю.

Важно: Telegram не может на 100% запретить скачивание, запись экрана, фотографирование экрана или использование модифицированных клиентов. Поэтому проект ограничивает штатную пересылку и несанкционированный доступ, но не является DRM-системой.

## Архитектура

Проект построен как layered application:

- `bot` - Telegram handlers, keyboards, FSM и middleware;
- `web` - FastAPI routes, admin panel, webhooks;
- `services` - бизнес-логика;
- `repositories` - слой доступа к данным;
- `db.models` - SQLAlchemy-модели;
- `config` - Pydantic Settings;
- `common` - общие enum, logging и security helpers;
- `cli` - сервисные команды.

Бизнес-логика не смешивается с Telegram handlers и web routes. Это упрощает тестирование, поддержку и расширение проекта.
